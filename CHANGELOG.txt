v1.2.0

- Short commands: any letters that fit a single command work (sc p, sc s, sc r, sc ni, sc p save gaming);
  when several fit (sc n) they are suggested, and a screen the letters could mean stays one row away
- Settings panel (sc settings): profiles screen by screen with live preview on the screens,
  try without saving, rename / duplicate / reset; nicknames, values and HDR per screen.
  Opens as an app window in Edge, Chrome, Brave or Vivaldi (else the default browser);
  runs on this computer only and goes away once the window is closed.
  Has its own window icon, title bar colour and dialogs, shows unsaved changes, says why a screen
  can't be changed, and works with the keyboard
- Your own profiles apply by name (sc gaming), like day / night / movie
- Profile names complete as you type: sc gam, sc profile gam, sc profile save g, sc profile delete
- Profiles show what they would change right now (1: ☀ 40→10%), and "✓ active" when they already match
- Saving over a profile shows what changes first ("Same as the saved settings" when nothing does)
- Names that already mean something (hdr, 50, #2...) are refused; a name that hides a screen word is flagged
- Live feedback: after a change, a ✓ row at the top of the list says what happened and what it was before
- Undo from that row (Enter): levels, HDR, profiles applied, saved or deleted, nicknames;
  repeated changes (sc +10 three times) undo back to the start
- Successful actions no longer pop up a Windows notification (errors still do)
- Previews skip screens without DDC/CI instead of promising changes they can't make

v1.1.0

- Profiles: sc day / night / movie, or save your own (sc profile save gaming)
- Nicknames: sc name #2 Gaming; follow the monitor across ports
- Shortcut: Ctrl+Alt+Shift+C opens sc (installer option --hotkey, rebindable in Flow)
- Windows HDR switch at the top of sc hdr (all screens at once, like Win+Alt+B)
- Shift+Enter quick actions: brightness/contrast presets, HDR, identify
- sc ? lists every command; sc shows a command menu
- Half-typed commands suggest how to finish them instead of showing an error
- Readable in light and dark themes: accessible screen colours (white digits >= 4.8:1),
  no text drawn over value bars, theme-coloured icons, identify overlay follows Windows mode
- Clearer DDC/CI errors (stuck monitor, unsupported setting, Remote Desktop...)
- Faster: ~90 ms Flow startup, instant queries from cache, screens re-read in the background every 30 s
- Self-healing: a supervisor restarts the plugin after a crash or hang and
  always answers Flow; sc reset (and Enter on error rows) resets everything
- Value bars show the current % inside them
- Fix: crash when Flow cancelled a query while typing
- Fix: plugin process spinning after Flow closed it (flogin read loop)

v1.0.0

- Brightness and contrast per screen or for all screens, absolute (sc 50) or relative (sc +10)
- HDR on/off/toggle per screen, or for all screens at once (sc hdr, sc hdr on)
- Identify screens: a big coloured number is shown on each screen (sc id),
  matching the numbered icon in Flow
- Screens are numbered left to right and described by position, primary,
  size, resolution, refresh rate, connection and serial number
- Target a screen by number, name, brand, position or connection (sc #2 80, sc lg 40)
- No network access or runtime installation; no compiled dependencies
- Hardware access on a background thread with timeouts, retries and caching
